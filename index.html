＋ নতুন Custom Bus তৈরি করুন

এখানে Layout লিখলে সেটি ব্যবহার হবে। খালি রাখলে Trip-এর Seat Layout Type থেকে Layout নেওয়া হবে।

এই Region-এর Schedule শুধু এই Region-এ অনুমতিপ্রাপ্ত Counter ID দেখতে পারবে।

✦ Saved Route Library

আগের সংরক্ষিত Route ব্যবহার করুন অথবা নতুন Route তৈরি করুন। Route একবার তৈরি হলে কোম্পানির Library-তে থাকবে।

✦ Saved Route সম্পাদনা

এই Route-এর নাম, Region, Direction এবং Stop List পরিবর্তন করতে পারবেন। Stop List-এর লাইনের ক্রমই Stop-এর ক্রম হবে।

প্রতি লাইনে স্থান|সময়|BOTH / BOARD / DROP / NONE|নোট। নতুন লাইন যোগ, মুছে বা ওপর-নিচ করে ক্রম বদলান।

তালিকা থেকে নির্বাচন করলে Name ও Phone অটোমেটিক পূরণ হবে। নতুন নাম Schedule Save করলে তালিকায় যোগ হবে।

✦ Custom Boarding & Dropping Points

নিজে যেকোনো জায়গার নাম ও সময় যোগ করুন। প্রয়োজনমতো একাধিক Point যোগ বা বাদ দিতে পারবেন। সময় ২৪ ঘণ্টা ফরম্যাটে দিন।

প্রতিটি জায়গার নাম ও Boarding Time লিখুন। “+ নতুন জায়গা যোগ করুন” দিয়ে আরও Point যোগ করুন।
প্রতিটি জায়গার নাম ও Dropping Time লিখুন। “+ নতুন জায়গা যোগ করুন” দিয়ে আরও Point যোগ করুন।

✦ Trip-এর নিজস্ব Seat Plan

প্রতি লাইনে Seat|Row|Position|Order লিখুন। খালি রাখলে Coach-এর বর্তমান Layout ব্যবহার হবে।

সংরক্ষিত Seat Format

Format নির্বাচন করলে নিচের Seat Layout-এ বসবে। মাঝখানে কোনো লেখা/লেবেল থাকবে না।
নিচের Seat তালিকা পরিবর্তন করে নিজের Format Save করতে পারবেন। Seat যোগ/বাদ করতে প্রতিটি Seat-এর একটি করে লাইন যোগ/মুছুন।
প্রতি লাইন: Seat Number|Row|Position|Order। এখানে মাঝখানে কোনো লেখা তৈরি হবে না।

Trip তথ্য Supabase-এ সংরক্ষণ করা হবে।

নতুন Counter তৈরি করুন

Counter তৈরি হলে Database নিজে থেকে একটি Unique Counter ID তৈরি করবে। এটি Counter Operator-এর Login ID নয়।
নতুন Counter তৈরি করতে নাম লিখুন।

নতুন Sub Manager Login তৈরি করুন

Company Manager নিজের Company-তে এবং Super Admin নির্বাচিত Company-তে Sub Manager Type ও Assigned Region নির্বাচন করে ID তৈরি করতে পারবেন। Type অনুযায়ী আগের Permission থাকবে; Assigned Region অনুযায়ী Schedule ও Counter সীমাবদ্ধ থাকবে।
Region, নাম, Login ID ও Password দিয়ে Sub Manager তৈরি করুন।

নতুন Counter Operator Login তৈরি করুন

প্রথমে Counter তৈরি করুন। এরপর Counter নির্বাচন করে Operator-এর Login ID ও Password তৈরি করুন। একটি Counter-এ একসঙ্গে একটি Active Operator ID রাখা যাবে।
Custom Point Save করলে ID তৈরির সময় নির্বাচিত Schedule Region-গুলোর Boarding Point suggestion-এ যুক্ত হবে (NB / DHAKA / SB)।
Counter নির্বাচন করে Operator ID তৈরি করুন।

Counter Operator ID পরিচালনা

এখান থেকে নিজের Company-র Operator/Agent Login ID-এর ধরন, Schedule Region এবং Active Status দেখা ও পরিচালনা করতে পারবেন। Deactivated ID দিয়ে Login করা যাবে না।
